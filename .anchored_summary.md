# ShelfSight Development Summary

## Objective
Match CLI feature set to VB6/FLTK versions.  Provide lightweight GUI options for Linux: ImGui (GLFW+OGL) and Tcl/Tk.

## GUI Options

### `shelf_gui --gui` (ImGui)
- ImGui v1.91.8 with GLFW + OpenGL 1.1 backend (fixed function pipeline)
- Full FLTK-style menu bar: Books, Readers, Loans, Databases, Settings, Account, About
- 28 view functions covering all CLI operations (add/edit/delete/list/search books/readers/loans)
- Movable, resizable window (780x560 default, remembers size)
- Live resource monitor: RAM in MB, CPU in ms
- Optimized `imconfig.h`: no SSE, no obsolete functions, no demo/debug

### `shelfSight --tk` (Tcl/Tk)
- **NEW** — Tcl/Tk 8.6 via C API, no external deps beyond `tcl8.6`/`tk8.6`
- 39 C command handlers bridging Tcl ↔ file_man/glob_vars C++ layer
- Full menu bar matching ImGui layout with 28 views
- Uses ttk widgets for native look on Linux
- Embedded Tcl script (~370 lines) as C++ raw string literal — no external .tcl files
- Binary (stripped, with Tcl/Tk dynlinked): ~1.2 MB (ImGui+GLFW still linked in)

### `shelf_nuklear` (experimental)
- Nuklear single-header C library with GLFW+OGL1.1 renderer
- Partial: menu bar, login/register/add-books views working
- Rest are stubs ("not implemented yet")
- Mostly superseded by Tcl/Tk choice

## Compilation scripts
- `compile-win95-98-me.sh` — i686 MinGW, Win95/98/Me
- `compile-win2k-xp-x86.sh` — i686 MinGW, Win2000/XP x86
- `compile-win2k-win11-x64.sh` — x86_64 MinGW, Win2000–Win11 x64

## Files
- `src/gui_imgui.cpp/.h` — ImGui GUI (778 lines)
- `src/gui_tcl.cpp/.h` — Tcl/Tk GUI (1153 lines, includes embedded script)
- `src/gui_nuklear.cpp/.h` — Nuklear GUI (partial)
- `src/main.cpp` — dispatches to `--gui` (ImGui), `--tk` (Tcl/Tk), or CLI
- `src/imgui/` — ImGui v1.91.8 core + backends
- `src/nuklear.h` — Nuklear single-header library

## CLI feature set (unchanged)
Reader format `name|surname|grade|class`, loan expiration dates, backup/restore, VB6 CSV import, settings persistence, configurable loan duration.
